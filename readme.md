# 🎲 Streamlit 로또 번호 생성기 (Lotto Number Generator)

파이썬(Python)과 스트림릿(Streamlit)을 활용하여 만든 간단하고 직관적인 **로또 번호 생성기 웹 애플리케이션**입니다.

## ✨ 주요 기능
- **로또 번호 생성**: `1 ~ 45` 사이의 숫자 중 중복 없는 6개의 번호를 무작위로 추첨합니다.
- **오름차순 정렬**: 추첨된 번호는 보기 좋게 오름차순으로 정렬됩니다.
- **최대 5게임 누적**: "로또번호 생성" 버튼을 계속 누르면 최대 5개까지의 게임 결과가 화면에 누적됩니다.
- **깔끔한 UI**: 애니메이션이나 효과음 없이 심플하게 구성되어 있습니다.

---

## 🚀 로컬 실행 방법 (How to Run)

1. 이 저장소를 클론하거나 코드를 다운로드합니다.
2. 터미널(명령 프롬프트)에서 프로젝트 폴더로 이동한 후, 필요한 라이브러리를 설치합니다:
   ```bash
   pip install -r requirements.txt
   ```
3. 스트림릿 앱을 실행합니다:
   ```bash
   streamlit run lotto.py
   ```
